## 一页结论：现在的真实处境

### 已完成且站得住的

| 资产 | 规模 | 价值 |
|---|---|---|
| 246 POI → 122 处理场地的**逐点审查** | 179 组近邻关系，严格合并 = 0 | 数据与可追溯性贡献 |
| **7381 对**道路查询时间（122 点全候选） | 中位 53.5 min，max 170.3 min | 真实地理依据 |
| **静态主线 A/B/C** | 6912 轨迹 / 2304 条件 | C−B：265 优 / 311 平 / 0 劣（修订标签版） |
| **接纳上限 ρ 与阈值 γ 的解耦** | 2424 闭包 + 840 γ 扫描 | ρ=1 时三算法差 0.07 pp；ρ=1.1 时差 42.3 pp |
| **安全承接最大流证书** | 200 图 + 642 前沿点 | `E*(Q) = max(0, Q−Q_s)`，证明正确 |
| **前瞻信息边界定理** | 50 + 104 项复核 | `f* = H−1`，运输时滞不能单独限定预告范围 |
| **同信息策略对照** | 283 项独立核验 | 分批严格优于最佳单次：638—654 / 798 |
| **承诺溢价充要条件** | 798/798 | `溢价=0 ⟺ 逐槽最小包络够` |

### 三个必须承认的结构性问题

**① 绝对服务水平不可解释。** `K = 1.25L` ⇒ 全部 122 节点 `u ≡ 0.800` ⇒ 容量约束从不 bind ⇒ 过载型级联无法自发产生。V7 表 4 中 C 的失效率恒为 19.03 **不是稳健，是容量没参与的指纹**。

**② 20 个百分点由单一不可行工况产生。** 前三档均值仅 1.7—3.0 pp，中位数 0；20 pp 完全来自「外围+150%」档（总需求 1.375 × 名义负荷 > 总能力 1.25 × 名义负荷）。该档即使**不损伤任何节点**，A/B 也全网退出。

**③ γ=1 是刀口。** γ∈(1, 1.1] 内 C−B 反转成 B ≥ C，而全文只固定 γ=1、无敏感性分析。一位评审只需问「把 γ 改成 1.1 会怎样」。

## 怎么用这个包

### 如果你要**投稿**

走 `02_研究方向/00_方向总览与推荐.md` §2 的**路线①（B+A 合并收口）**：约 2 天写作 + 1 次 γ 敏感性补跑，3 区稳。

**投前必做**：读 `06_稿件/V7_问题清单.md`，按 P0 → P1 → P2 修。P0 只有三条：补 γ 扫描、摘要头条改中位数、表 4/5/11 分档报告。

### 如果你要**继续做研究**

走**路线②（方向 C）**：3—5 个研究工作日做可行性核验，先补**转运速率上限**（否则「至少提前转出多少」恒为零），再做精确小例与同信息基线。

### 如果你要**复现某个结果**

`01_实验结论/00_总览_全部实验结论.md` 每条结论都给了证据位置。数据在 `04_数据/04_核心结果表/`，代码在 `03_代码/`。

### 如果你要**查某个说法能不能写**

先查 `02_研究方向/09_已否决与沉没成本.md` §2「已作废的推导」和 `10_近邻文献与创新边界.md` §5「不能宣称的清单」。

## 三条数据可信度硬约束（贯穿全包）

1. **绝对服务水平不可解释** —— 同一 122 图仅换风险分母，C 服务变化 −38.35 ~ +88.00 pp
