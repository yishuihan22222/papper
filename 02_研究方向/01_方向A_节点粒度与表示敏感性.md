## 1 一句话

同一个物理系统，用细粒度（246 个 POI）和粗粒度（122 个处理单元）表示，级联结论差多少？

## 2 为什么值得做

- 输入的地理与统计部分是真的（POI + 道路查询 + 年鉴 + 4 个能力锚），不需要编造数据
- 结论是方法性的、可迁移的，不绑死武汉
- **已有对照显示效应量差 50 倍**（共同任务 246 图 0.41 pp → 修订 122 图 20.20 pp），但现有对照**被容量混淆**（246 点用 246 份容量、122 点用 122 份容量）
- 文献里少见的「分辨率敏感性」研究

## 4 可用的代数关系（已推导，可直接写）

设非负风险分子 `H_v(F)`，诱导图度数 `d'_v`，原图度数 `d⁰_v`，令

```
q_v = max(d'_v,1) / max(d⁰_v,1)
P'_v(F) = H_v(F)/(0.68·max(d'_v,1)) + β_v
P⁰_v(F) = H_v(F)/(0.68·max(d⁰_v,1)) + β_v
```

则逐节点精确恒等式

```
P'_v(F) − β_v = (P⁰_v(F) − β_v) / q_v
```

在两规格共同满足「至少一个失效邻居」门控时，诱导分母的触发条件等价于

```
P⁰_v(F) ≥ β_v + q_v(θ − β_v)
```

⇒ **即使名义 θ 未变，分母改变也改变逐节点有效阈值。**

**边界**：这是模型代数诊断，**不是**新阈值理论（分数阈值与度数易损性见 Watts 2002、Smolyak 2020）。若换图同时改变风险分子、边属性或 β，不能用这条恒等式直接分解联合变化。

## 5 必须补的实验（关键）

固定总容量 ΣK 与总需求 ΣD，只改节点粒度：

1. 把 122 个处理单元的 K 按**真实层级映射**拆回 246 个 POI（或反向合并）
2. 跑三档粒度：246 细 / 中间档 / 122 粗
3. 报告 C−B 效应量随粒度的变化曲线

**但 `选题建议复核` 已指出这一步不像看起来那么干净**：

| 原设想 | 核对后判断 |
|---|---|
| 246 POI 与 122 处理单元是细、粗两档粒度 | V7 含角色剔除、证据未闭合隔离、层级代表处理；**严格证实的同一单元合并为 0** |
| 固定总 D、总 K 即可隔离粒度效应 | 还涉及空间服务范围、功能、可达、损伤投影和风险分母 |
| 输入全真，因此粒度方向不需标定 | 地理和统计有事实依据，**L/K/风险仍是代理** |

⇒ 不能直接按组成关系拆分或聚合 K，**先要建立真实层级映射**。

## 6 附加校验（把「贴实际」做实）

用 4 个真实锚点检验代理模型的份额分配：引力模型给花湖机场（2808 吨/天）、阳逻港、丰泰的份额，与真实吞吐量是否成比例。

**已算出：系统性低估枢纽 38 倍**（模型最大节点 1.09% vs 真实丰泰 41%）。这本身就是一个可发表的方法缺陷 → 见方向 D。

## 7 停止线

| 触发现象 | 处置 |
|---|---|
| 三档粒度效应量差异 < 2 pp | 放弃此方向，转方向 B |
| 无法建立真实层级映射 | 降级为「审查协议 + 表示敏感性描述」，不做因果归因 |
