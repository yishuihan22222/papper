## 2 三条推荐路线（按用户约束排序）

### 路线①　B + A 合并收口（最省力，零新实验）

> 标题方向：**《节点粒度与接纳上限：城市物流网络级联结论的两个敏感源》**

- **前半**：POI→处理单元的审查协议 + 粒度敏感性（数据与方法贡献，全真数据）
- **后半**：审查后网络上，ρ 与算法、γ 的交互（机制贡献，现成结果）
- **命题**：这类模型的结论主要由**表示方式**与**规则设定**决定，而非算法选择
- **工作量**：约 2 天写作 + 1 次 γ 敏感性补跑
- **风险**：V7 的 γ=1 刀口问题必须先补 γ 扫描，否则一位评审问「把 γ 改成 1.1 会怎样」就能让全文核心结论失效

### 路线②　C 主线（最贴用户「要现实联系」的诉求）

> 工作题目：**《接收余量流失下的限时等待与分批分流决策》**

- 一句话研究问题：恢复时间不确定、接收余量会随等待减少时，最迟还能等多久、至少应提前转出多少，才能保住完成期限并减少不必要转运？
- **已有**：三轮网格、同信息对照 283 项核验、前瞻边界定理
- **缺**：状态/动作/同信息精确基线、二分位边界到分批规则的桥
- **必须补的机制**：**转运/接收速率上限**（否则「至少提前转出多少」恒为零，见 §4 陷阱 1）
- **档位**：首版 3 区可投；把余量流失做成内生（他人分流或随机流失）= 唯一 2 区升级口

### 路线③　D 现实连接短文（可作为 C 的一节，也可独立）

> 标题方向：**《代理负荷的集中度检验：城市物流级联模型的绝对水平为何不可解释》**

- 四命题：R1 时滞不 bind / R2 集中度失配 38 倍 / R3 容量不参与（u≡0.800）/ R4 绝对水平不可解释

## 4 四个必须提前知道的陷阱

### 陷阱 1　「至少提前转出多少」在无速率上限时恒为零

设定：余量按外生情景流失 `C(t)=C₀−ρt`，任务可分批，转出不可撤回，**转运无速率上限**。

设批量 x，t=0 转出 y，余下 x−y 在时刻 t 再转：

- 时刻 t 可用余量 `C₀ − y − ρt`；仍需转出 `x − y`
- 可行性 `C₀ − y − ρt ≥ x − y` ⟺ **`C₀ − ρt ≥ x`**（与 y 无关）
- 完成时刻 `t + τ + (x−y)/K`，**随 y 增大而变晚**

⇒ **最优解恒为 y = 0**，第二个问句是空的。

**补救**：加**转运/接收速率上限** `m`，设 `β = mK/(m+K)`（串行，最保守），则

```
y*(t) = max{ 0 ,  x − β(h − t − τ) }        ← 最低提前转出量
t*    = min{ h − τ − x/β ,  (C₀ − x)/ρ }    ← 最迟等待时刻
∂y*/∂t = β > 0                              ← 等得越久，现在必须先转出越多
```

`∂y*/∂t = β > 0` 是**反直觉且可检验**的主结果：等待不是「少转」，而是「早转更多」。

另：分批 minimax 平衡点 `y° = (r − τ + x/K)/(1/β + 1/K)`，用 `r_max` 得鲁棒解。**`y°` 与 `y*(t)` 是两个不同量，论文必须分清。**

### 陷阱 2　把可行性边界写成最优性边界

四格必须分清：

| | 外部可接住 | 外部接不住 |
|---|---|---|
| **本地可按期** | **真正的决策区**（等待可行但未必最优） | 等待是唯一可行 |
| **本地不可按期** | 必须外转，且外转可行 | 无解（只能改期限或改结构） |

**只有左上格是决策问题。** 两个无分布边界（`r_max+x/K≤h` 必然可等；`r_min+x/K>h` 必然不可等）只判断**本地可行性**，不等于最优。

### 陷阱 3　把查询估计值写成实测

D02—D05 全部是**路径规划查询的预计行驶时间**，不含实时拥堵、装卸、排队与交接。写成「实测通行时间」就是一个可被攻击的点。

### 陷阱 4　混用不同节点集的统计量

| 节点与边集 | 对数/边数 | p50 | max |
|---|---:|---:|---:|
| 原 246 点，全候选对 | 30126 | 55.78 | 193.25 min |
| **同 122 点，全候选对** | **7381** | 53.55 | 170.32 min |
| 同 122 点，稀疏模型边 | 1624 | 17.65 | 63.03 min |

**30126 是 246 点的，不是 122 点的。** 同一城市、同一节点集，仅因边集不同，τ 上界差 2.7—3 倍 → **τ 维度的强弱由稀疏化规则决定，不由城市决定**。
