## 1 一句话贡献候选

> **运输时滞不能单独确定充分的容量预告范围；即使运输很短，晚期接收窗口的信息也可能决定现在是否必须预防性分流。本文给出这一现象的条件和反例边界，并评估它对分流量与期限保障的影响。**

比「动态比静态好」具体，也不把「信息越多越好」包装成新发现。

## 2 问题与假设

- 离散时段 `t = 0,…,H−1`，在时段 H 开始前完成全部货物
- 源点恢复时刻 R 仅通过「已恢复/未恢复」**二元观察**；恢复支持已知
- 接收点容量日历属于**已知有限集合**；每时段准确获知当前及随后 **f 槽**的容量；无额外信号
- 运输需 L 槽；时段 t 派出的货最早在 t+L 接受服务
- 货可排队，但**过去未用的处理能力不能留到以后**
- **无派出速率瓶颈**；派出不可撤回
- 对全部恢复×容量情景保障按期完成；在此约束下最小化各情景**等权**转运量之和 `J_f`

**临界前瞻范围**

```
f* = min{ f : J_f = J_{H−1} }
```

表示达到「初始知道整条容量日历、仍不知道恢复时刻」的基准表现所需的**最短准确预告范围**。**不是**保障按期所需的最短范围。最坏转运量与等权转运量不能混用。

## 3 命题

对任意整数 `H ≥ 3`、`1 ≤ L ≤ H−2`，取：

- 货量 `x = H−1`，源点恢复后每槽处理 `K = 1`
- `R ∈ {1, H}`，与容量日历取**全部组合**
- 日历 A：仅在时段 L 提供 x 的能力
- 日历 B：在时段 L 和 H−1 各提供 x 的能力，其余时段为零

则四个情景满足：

```
J_f = 4x ,  0 ≤ f ≤ H−2
J_f = 3x ,  f = H−1
⇒  f* = H−1
```

**特别地**：固定 `L = 1` 而增加 H，必要前瞻相对于运输时滞的比值**可任意增大**。

⇒ **在本模型类中，不存在仅以运输时滞为依据的通用有限充分前瞻范围。**

## 4 证明（两段）

**有限前瞻（f ≤ H−2）**：时段 0 无法区分 A 与 B，也无法区分两个恢复时刻。在情景 `(A, R=H)` 下源点期限内完全不能处理，外部唯一服务机会在时段 L。利用这一机会必须在时段 0 派出全部 x；任何晚于 0 派出的货均赶不上。**相同观察历史必须采取相同行动**，所以四个情景都在时段 0 派出 x。这既必要又可行，故 `J_f = 4x`。

**初始预知日历（f = H−1）**：
- 若已知 A，两个恢复情景仍在时段 0 不可区分，均必须派出 x，合计 `2x`
- 若已知 B，可等到时段 1：若源点恢复，剩余 H−1 槽足以本地完成，派出 0；若仍未恢复，根据二点支持即可确定 `R = H`，最迟在 `H−1−L ≥ 1` 派出 x，利用最后一槽完成。B 的两个情景合计 x，且晚恢复情景必需转运 x，故这个值最优

⇒ `J_{H−1} = 3x`。证毕。

**重要边界**：`4x → 3x` 是**这个构造的 25%**，不是武汉运营降本比例。所有信息情景的**最坏**转运量仍是 x；收益来自较好情景少转运，**保障可行性没有改善**。

**归一化**：`L/H`、`f*/H = (H−1)/H`、`x/(KH) = (H−1)/H`。取 `L = 1` 时，运输占期限比例趋于 0，而必要前瞻比例趋于 1。

> 这说明「运输相对期限短」本身**不能**推出「短容量预告足够」。

## 5 独立复核

| 批次 | 内容 | 结果 |
|---|---|---|
| 第一批 | H=3,4,5,6 × 全部 L=1…H−2，共 10 组期限—时滞组合；每组全部 f=0…H−1，共 **50 项** | 原 DP、独立情景树整数规划、上式**三者全部一致** |
| 第二批 | 50 项固定单位货量与能力 | 通过 |
| 第三批 | 50 项两种恢复时刻均早于截止期（`x=2, K=1, R∈{1,H−1}`，本地最晚仍能处理 1 单位） | 通过，`f*` 仍为 H−1 |
| 第四批 | 4 项可达服务槽能力均为正（`H=4, L=1, K=2, x=6`，日历 (0,3,1,1)/(0,3,1,3)） | 通过 |

合计 **104 项定向复核**全部通过。第三批排除了「结论仅因源点期限内完全不恢复」的疑虑。

## 6 数学核对的三个收紧表述

1. 「需要预告至截止期」是**达到日历已知基准的最小等权分流量**可能需要；没有预告仍可通过多分流保证按期。**不能说「没有长预告就无法完成」。**
2. 这是**存在性反例和一般充分界限的否定**，尚不是给任意实际日历直接算出所需预告期的解析公式。
3. 「不存在仅依赖运输时滞的通用充分范围」应明确为「通用**有限**充分范围」，并保留本模型条件和期限可变这一量词。

### 一篇必须保留的较早直接近邻

**Xu（2015），Necessity of Future Information in Admission Control，Operations Research 63(5):1213–1226。** 直接研究未来到达和服务信息揭晓时分流控制需要多长前瞻，在重交通条件下给出必要范围。

⇒ **「首次研究分流需要多少未来信息」不可使用。** 它是长期随机排队、限制分流率、优化平均队长；我们的有限期限、已知初始批量、双地点及最小分流目标并非其定理的直接特例。

## 8 一个会影响实验公平性的细节

**Filom 2025 的 2/4/6 小时 δ 是延误容忍阈值，不等于「等待满 δ 小时再把货全部转走」。** Algorithm 3 在每个决策时点更新服务信息，剔除延误超过 δ 的服务，然后重建路径、优化匹配并更新剩余容量。

因此「补固定等待缓冲对照」要拆成三类：

- **固定时刻一次分流**：保留为透明的简单基准，**不能**冠以 Filom 算法名称
- **文献启发的延误阈值筛选 + 重新优化**：迁移时须单独定义延误的估计方式，给合理参数调优，明确模型迁移边界
- **所有策略使用相同恢复信息、相同容量预告、相同期限和情景**；另设「日历已知」作为信息价值基准，**不把多知道信息的收益算成算法优势**

**同信息对照已做（2026-10-22 13:25）**：δ 门控在 δ/H ≤ 0.5 时 358/798 找不到保障方案、220 组劣于 DP；δ/H ≥ 0.75 时退化为标准滚动流（0 组劣）。**迁移版没有独立增量。**

## 9 怎样继续

推荐的贡献定位：**面向限期完成的容量窗口感知分批分流规则及其信息需求。**

| 状态 | 内容 |
|---|---|
| **已站住** | 一个具体模型中的反例边界；可复现的分批规则与精确对照；信息不足造成额外分流的结构证据 |
| **尚未站住** | 相对最接近可迁移规则的独立增量；实际日历下信息需求的简便诊断 |

**最小下一步**：同条件规则对照（已完成），观察具体在哪些窗口结构下改变决策、少转多少、何时没有改善；接着用现有道路时间做尺度映射。

**不需要**为了「小创新」增添新数据、新博弈或新算法。
