## 6 反复出现的方法论教训（写给自己看）

| 教训 | 具体表现 |
|---|---|
| **不要把「模型结构决定的」当成「仿真发现的」** | C 不崩（ρ=1 ⇒ u≤1）、B 全崩（ρ=1.1 且 γ=1 ⇒ 必退出）都是定义推出来的 |
| **不要把异常读成稳健** | 表4 中 C 失效率恒为 19.03 不是稳定，是容量没参与的指纹 |
| **不要把可行性当最优性** | 两个无分布边界只判断本地可行性 |
| **不要用自选参数支撑主结论** | γ=1、ρ=1.1、K=1.25L 全是自选 |
| **不要把网格占比当现实概率** | 576 / 2808 / 14160 都不是独立灾害样本 |
| **不要为逃离标准模型硬加非线性** | 加博弈/加非线性只会制造新的可攻击点 |
| **不要靠增加算例规模提升档次** | 增加决策时刻/接收点/场景只增加篇幅 |
| **先找反例，再谈结构** | 单调性与阈值存在性都要验证，不能先画想要的形状 |
