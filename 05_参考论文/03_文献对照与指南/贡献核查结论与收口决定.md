# 贡献核查结论与收口决定

日期：2026-10-21。对象：V7节点整改后的静态物流派入—级联模型。目标：判断当前论文能守住什么贡献、应放弃什么主张，以及收口前必须完成的最少工作。

**决定：以“条件性策略排序与网络表示敏感性”收口，放弃新调度算法和普遍策略优势的定位。当前证据尚未建立强独立方法创新；这轮核查也不能保证中科院三区录用。** 可保留的价值是：说明一个看似稳健的排序为什么成立，以及该排序为什么不能保证绝对服务水平可信。把模型证明、业务对象审计与同一网络内的规格对照连成一条论证，比继续堆机制和参数更有用。

本轮新增的是文献对照与既有结果的分母单因素再核算，没有新增级联仿真，没有修改V7正文、Word、原始数据或已有结果文件。逐条件表、文献矩阵、主张裁决及检索记录均在本目录。

## 1. 核查范围与证据等级

- 对照8篇直接近邻、3篇基础研究，共11条去重DOI。8篇近邻中6篇取得本地全文材料，2篇仅完成出版社索引章节/摘要及元数据核查。
- 本地全文的“取得”不代表逐字精读：本轮核阅模型、约束、失效语义、目标及评价相关章节，页码与公式锚点列于[近邻文献对照](01_近邻文献对照.csv)。基础文献用于判断结构是否已有，不代替逐领域比较。
- 读取既有10篇PDF并提取文本；其中5篇进入直接近邻主表，另外5篇仅保留清单，不能冒充全部深读。补充公开预印本和PMC全文，用来核对阈值传播、终态控制及表示有效性。
- Crossref与OpenAlex用于书目信息，期刊/作者公开全文用于方法证据。部分API返回429；部分出版社返回403或证书错误，均记录，不绕过访问限制。没有从未取得的全文推断“对方没有做”。
- 检索是围绕本稿候选贡献的定向多源审计，不是系统综述，也不是全球新颖性认证；未检到相同论文不能写成“首次”。没有在本轮核验期刊中科院分区。

## 2. 三条必须改变定位的文献证据

**设施间逐轮重分配优化已经有直接近邻。** Cao等在全球集装箱网络中，联合选择接收港和分配量，兼顾运输时间、利用率及过载港数，并在后续轮次继续传播。其容量也使用λWi假设。关键差异是指定重分配量守恒等式，而本稿允许自由拒收；本稿B/C还改变了接纳可行域。因此，不能把两套模型输出高低当作算法水平差异。其改进MSA/Logit是在接收港层分配，不是完整道路OD用户均衡。[Cao等，2025，TRA](https://doi.org/10.1016/j.tra.2025.104659)，PDF p6–12、Eq7及§3.3。

**“当期等价决策可能导致不同级联”也已有先例。** 电网研究已明确研究最低费用等价派电解与后续停电统计的关系，并关联网络异质性。该行业差异不能抹掉先例，也不能直接替代本稿证明。该文仅核到出版社索引首页/摘要，不能据此判断全文全部边界。[Reynolds-Barredo等，2016](https://doi.org/10.1063/1.4967736)。本稿三节点例没有固定费用，150条件三目标等价最优解对照则没有终态差异；应保留这个零结果。

**区域物流中的“阈值闭包＋LP流量”组合已有更近研究。** 2026年长江经济带28港研究的方法文字给出度损失闭包与存活网络流量优化。本稿含派入过载反馈，仍有机制差异；但笼统框架组合不足以支撑新颖性。该文公式及拒收口径未完整读取，不进行逐式等价判断。[Ding等，2026](https://doi.org/10.1080/03088839.2026.2676604)，§3.1–3.2及算法1。

其他对照进一步限制主张：Yu等已有多机制相依网络和剩余容量分配；Qu等已有负荷依赖风险与过载耦合；Hasenjager等已有订单完成/未满足需求评价；Ba与Savla已有以削减供需维持稳定终态的控制模型。本文外生风险、不允许恢复、无道路共享拥堵的限制必须直接说明，不能把这些限制产生的可证明性包装成一般理论突破。

## 4. 本轮完成的最小分析：只换分母会发生什么

此前“修订122图与原246图”的比较同时改变接收资源、可达、风险暴露和分母，无法单独解释归一化。V7已有另两组可以直接配对：

1. `candidate_induced`：122点诱导图，沿用历史功能标签，以诱导图度数作风险分母。
2. `candidate_fixed_degree`：同一122点图、同一历史功能标签，仅改用原246图度数作固定风险分母。

两组的节点、边、K、任务、投影冲击、场景加项、派入目标和阈值一致。这里的功能标签是两组共同沿用的历史标签，**不是修订标签主版本**。本轮从冻结输出配对1728条A/B/C条件，不重新运行优化器或级联。任务分母相同、配对键唯一及来源文件SHA-256保持均已核验。

对C的576个条件，改用较大的原246度数分母后：

| 指标 | 结果 |
|---|---:|
| 终态服务率平均变化 | +8.658351个百分点 |
| 中位变化 | 0 |
| 最小—最大变化 | 0至+90.482182个百分点 |
| 提高 / 持平 / 降低 | 234 / 342 / 0 |
| 固定分母闭包包含于诱导分母闭包 | 576 / 576 |

最大差出现在基准容量、名义需求、既有通道冲击、最低阈值条件：服务率由约9.5178%变为100%。这是模型规格敏感性，不是现实服务提升，也不是更大分母更真实。

按三阈值分层，平均变化约24.3604、1.5036、0.1111个百分点；三档分别192条件。它不是每个场景都很大：342条件不变，中位数为0。A在本对照的全部576条件不变，B提高138条件、持平438条件。B的方向是该网格观察，不自动获得C的单调性证明。

122节点中119个度数变化，3个诱导图孤立点。包括正度数点在内，邻域分数项的最大比例放大为12倍。不能把此数乘到整个风险评分上，因为场景加项不随分母缩放；孤立点没有失效邻居，不触发风险通道。

来源：[逐条件配对](既有结果再核算/01_same122_degree_only_pairs.csv)、[分容量政策汇总](既有结果再核算/02_degree_only_summary.csv)、[逐节点度数](既有结果再核算/03_degree_scaling.csv)、[检查与来源哈希](既有结果再核算/04_summary.json)。这是事后描述性再核算，网格不是576次独立灾害，不计算现实胜率或显著性。

## 5. 解释这个结果的代数关系及适用条件

在同一122点图、同一失效集合F和相同场景加项下，记非负风险分子为Hᵥ(F)，诱导图固定度数为d′ᵥ，原图固定度数为d⁰ᵥ。定义：

\[
q_v=\frac{\max(d'_v,1)}{\max(d^0_v,1)},\quad
P'_v(F)=\frac{H_v(F)}{0.68\max(d'_v,1)}+\beta_v,\quad
P^0_v(F)=\frac{H_v(F)}{0.68\max(d^0_v,1)}+\beta_v.
\]

则逐节点有精确恒等式：

\[
P'_v(F)-\beta_v=\frac{P^0_v(F)-\beta_v}{q_v}.
\]

在两规格共同满足“至少一个失效邻居”的门控时，诱导分母的触发条件等价于：

\[
P^0_v(F)\geq \beta_v+q_v(\theta-\beta_v).
\]

因此，即使名义θ未变，分母改变也改变逐节点有效阈值；这不仅是边数表格的变化。q≤1且H≥0时，P′≥P⁰；在外生单调风险和相同初始失效条件下，固定原分母的纯风险闭包包含于诱导分母闭包。C等于纯风险闭包，并在自由拒收的终态总完成目标下得到较大的可用安全服务空间，所以C的方向有结构性解释。

**这是模型代数诊断，不是新阈值理论。** 分数阈值与度数易损性已有成熟研究，见[Watts，2002](https://doi.org/10.1073/pnas.082090499)及[Smolyak等，2020](https://doi.org/10.1038/s41598-020-72771-4)。本稿有用的部分，是将该关系与业务节点整改、冻结任务以及终态服务比较具体连接。

关系或方向的边界：若换图同时改变风险分子、边属性或β，不能用这条恒等式直接分解联合变化；若风险依赖派入量、道路拥堵或恢复过程，当前闭包包含与安全服务结论需要重证。若有拒收罚损、最低接纳、时限、公平或来源优先服务目标，C的终态总完成上界也不能直接当这些目标的最优性。

## 6. 推荐收口主线与可使用的贡献措辞

建议题目：**静态物流派入级联的条件性策略排序与网络表示敏感性**。

研究问题：在允许拒收、按额定能力核算完成量的静态派入级联中，哪些政策排序是模型结构保证的；当业务节点范围或风险归一化改变时，排序保持是否掩盖绝对服务水平变化？

可用贡献段：

> 本研究区分接纳、完成和不可逆退出，明确安全承接在外生单调风险等假设下的终态总完成上界。通过可追溯的物流处理场地候选审查，以及冻结任务、容量和冲击的规格对照，说明政策排序保持并不足以证明绝对服务水平对输入表示稳健。进一步用度数归一化恒等式解释同一网络上的阈值变化，并结合完成核算、精度边界及位置反馈的正例和零结果，界定模型结论的适用范围。

这是**本稿组合论证与可复现案例分析的贡献措辞**，不宣称每一组成部分首创，不承诺已经达到某个分区期刊的新颖性门槛。
