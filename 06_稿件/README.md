## 3 必读：V7 问题清单的核心结论

### 3.1 致命问题（P0）

**① γ=1 与 ρ=1.1 的组合决定了全部结论**

- B 的 LP 先把总派入量 X 最大化 → 每个可达节点填到 1.1K → 退出判据 u>1 → **每个接到 1.1K 的节点必然立即退出**
- **B 的全网崩溃是定义推出来的，不是仿真发现的**
- C 因 ρ=1，ℓ≤K，u≤1 → **永远不可能触发过载**
- ⇒ 比较 C 与 B 实际上是比较「两个机制」与「一个机制」，**机制效应与政策效应完全混淆**

**② 只要 γ 略大于 1，C−B 的符号会翻转**

- γ=1.1（=ρ）时 B 的 ℓ≤1.1K=γK，不再有过载退出，B 的终态失效集合 = C 的
- 此时 B 的完成量 ≥ C 的完成量 ⇒ **结论反转成 B ≥ C**
- 全文只固定 γ=1，**无任何 γ 敏感性分析**；而附录 C 的三节点构造自己用了 γ=1.075
- **建议**：扫 `γ ∈ {1.00, 1.02, 1.05, 1.075, 1.10, 1.20, 1.30} × 3 容量 × 4 需求`

**③ 政策 B 是稻草人**

- B 的第一目标使它在总需求超总能力时**必然接收 99.96% 的需求**，然后全灭
- 「最小化超额 E」作为第二目标在 X 已最优时几乎不起作用
- ⇒ B 不是「惩罚超额的派入策略」，而是「无条件全收 + 事后惩罚」
- **建议**：增加政策 D（把 E 放到第一目标），检验结论是否源于**目标顺序**而非容量约束

### 3.2 头条数字的聚合问题

- 表 5：总体均值 20.20—21.25 pp，但**前三档均值仅 1.72—2.98 pp，中位数全部 0.00**，提高/持平/降低 = 86/106/0
- 表 4：名义 6.07 / 鄂州+20% 5.61 / 外围+20% 8.36 / **外围+150% 74.58**
- ⇒ **20 pp 完全由「外围+150%」这一档产生**
- 该档总需求/名义总负荷 = **1.375** > 总能力/名义负荷 = **1.25** ⇒ **物理上不可行**
- **建议**：摘要头条改为「中位数 0，前三档均值 1.7—3.0 pp；仅当总需求超过总能力时出现 70 pp 量级差异」

## 5 总体判断（原文）

> 论文的**诚实度很高**——绝大多数局限都已主动写明，这在国内竞赛稿里少见。问题不在「隐瞒」，而在**把限定写在正文、把未限定的数字写在摘要**。

按现在的稿子，一位严格的评审只需问一句——「把 γ 改成 1.1 会怎样？」——就能让全文的核心结论失效。

**这个实验必须在投稿前做完，无论结果是否有利。** 如果 γ 扫描显示结论在 γ≥1.05 就消失，那么正确的写法不是补救，而是把论文改写成「派入规则的效果高度依赖过载退出规则的严苛程度，只有在过载立即不可逆退出的设定下容量硬约束才占优」——**这仍然是一个有价值的、更诚实的结论。**
