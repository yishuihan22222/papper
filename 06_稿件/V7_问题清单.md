## 一、致命问题：结论成立与否取决于一个从未检验的参数

### 1.1 γ=1 与 ρ=1.1 的组合决定了全部结论

- 设定（表3、三(一)）：A/B 接纳上限 ρ=1.1，C 的 ρ=1，过载退出界限 γ=1。
- 后果：B 的线性规划先把总派入量 X 最大化，因此会把每个可达节点填到 1.1K；而退出判据是 u=ℓ/K>1，于是**每一个接到 1.1K 的节点都必然立即退出**。B 的全网崩溃是定义推出来的，不是仿真发现的。
- 同理，C 因 ρ=1，ℓ≤K，u≤1，**永远不可能触发过载**（这正是命题 2 的内容）。所以"C 不崩"也是定义推出来的。

**这意味着：所谓"双机制级联"在 C 上根本不存在过载机制，只对 A/B 存在。比较 C 与 B 实际上是在比较"两个机制"与"一个机制"，机制效应与政策效应完全混淆。**

### 1.2 只要 γ 略大于 1，C−B 的符号会翻转（需作者立即验证）

- 若 γ=1.1（=ρ），B 的 ℓ≤1.1K=γK，**不再有任何过载退出**，B 的终态失效集合 = 纯风险闭包 Fᴿ = C 的失效集合。
- 此时两者失效相同，而 B 的完成量 = Σ min(Kⱼ,ℓⱼ) ≥ C 的完成量（C 的可行域是 B 的子集，且 B 的字典序"最大化 X 再最小化 E"恰好等价于"最大化 X 再最大化完成量"，因为完成量 ≡ X − E）。
- 也就是说：**γ=1 是唯一让 C 占优的取值，γ∈(1,1.1] 内结论会反转成 B≥C。**

全文（表3）只固定 γ=1，**没有任何 γ 敏感性分析**——这是最关键的一个缺失实验。而附录 C 的三节点构造自己用了 γ=1.075，说明作者知道 γ 是刀口，却没在主网格里扫它。

**建议**：补 γ∈{1.00, 1.02, 1.05, 1.075, 1.10, 1.20, 1.30} × 3 容量 × 4 需求的扫描，报告 C−B 随 γ 的曲线。若曲线在 γ≈1.1 处过零，必须在正文如实写明"结论仅在 γ<ρ 时成立"，并把标题/摘要的主张收窄为"当过载立即且不可逆地导致退出时……"。

### 1.3 政策 B 是稻草人

- B 的第一目标（最大化追加派入量 X）使它在总需求超过总能力时**必然接收 99.96% 的需求**（图4d），然后全灭。
- "最小化超额 E"作为第二目标在 X 已最优的前提下几乎不起作用——它只能在"已经全部接收"的前提下分配超额，无法拒绝。
- 因此 B 不是"惩罚超额的派入策略"，而是"无条件全收 + 事后惩罚"的策略。真实调度中不存在这种策略，用它对标 C 得到的 20pp 不能解释为"限制超额的价值"。

**建议**：增加第四个政策 D——把 E 放到第一目标（先最小化超额、再最大化派入），这才是一个真实可用的"超额厌恶型"策略。如果 D 与 C 接近，说明结论的本质是"目标顺序"而非"容量约束"。

## 二、头条数字的聚合问题（摘要 20.20—21.25 pp 站不住）

### 2.1 均值被单一工况拉动，中位数为 0

- 表5：122 点修订标签版，总体均值 20.20—21.25 pp，但**前三档均值仅 1.72—2.98 pp，差值中位数全部为 0.00**，提高/持平/降低 = 86/106/0（即 55% 的条件完全无差别）。
- 表4：基准容量下 名义 6.07、鄂州+20% 5.61、外围+20% 8.36、**外围+150% 74.58**。前三档均值 6.68，四档均值 23.66。

### 2.2 该工况在物理上不可行

- 图4a：总需求/名义总负荷 = 名义 1.000、鄂州+20% 1.007、外围+20% 1.050、**外围+150% 1.375**；虚线"总能力/名义总负荷"= 1.25。
- 即只有第四档 **总需求 > 总能力**，系统整体不可行。此时 B 崩溃、C 崩溃得少，是容量缺口 + 即时退出规则的算术结果，不构成"派入规则优劣"的证据。

### 2.3 图件已自证双峰，正文却用均值叙述

- 图3a：散点全部落在"对角线"与"B=0, C≈75"两簇，中间空白。
- 图3f / 图7：三档需求列几乎全白，第四列整列深色。
- 图7 的九宫格实际只传递一条信息："外150 那一列很深"。

**建议**：
1. 摘要头条改为"中位数 0，前三档均值 1.7—3.0 pp；仅当总需求超过总能力时出现 70 pp 量级差异"。
2. 主表改为**按需求档分层报告中位数与四分位**，删除或降级"总体均值"这一行。

## 九、总体判断

论文的**诚实度很高**——绝大多数局限都已主动写明，这在国内竞赛稿里少见。问题不在"隐瞒"，而在**把限定写在正文、把未限定的数字写在摘要**：

- 正文说"差值中位数为 0、前三档 1.72—2.98"，摘要说"20.20—21.25"；
- 正文说"该差距由能力缺口、超额接纳与即时退出共同产生"，摘要不说；
- 正文说"γ=1"，从不讨论 γ=1.1 会怎样。

按现在的稿子，一位严格的评审只需问一句——"把 γ 改成 1.1 会怎样？"——就能让全文的核心结论失效。**这个实验必须在投稿前做完，无论结果是否有利。** 如果 γ 扫描显示结论在 γ≥1.05 就消失，那么正确的写法不是补救，而是把论文改写成"派入规则的效果高度依赖过载退出规则的严苛程度，只有在过载立即不可逆退出的设定下容量硬约束才占优"——这仍然是一个有价值的、更诚实的结论。
