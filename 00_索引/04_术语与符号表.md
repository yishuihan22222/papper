# 术语与符号表

整理日期：2026-10-22

> **注意**：本文档中「实测」二字仅用于真正实测的量（POI 坐标、公开统计）。道路时间是**路径规划查询估计值**，容量与负荷是**代理量**。混用会直接导致结论被质疑。

---

## 2 边与阻抗

| 符号/术语 | 含义 | 公式/取值 | 性质 |
|---|---|---|---|
| `Distance_km` | 道路里程 | 0.01—91.69 km（15% 主图） | 查询估计 |
| **`Duration_mins`** | 预计通行时间 | 主图 0.02—81.58 min | **查询估计，非实测** |
| 广义阻抗 | 混合尺度代理量 | `0.4×距离 + 0.6×时间` | **非分钟、非公里** |
| `Cross_district` | 跨区县指示 | 1/0 | 非跨江桥梁标记 |
| `Functional_synergy` | 功能协同映射 | 类型组合固定值 | 不证明可接替同种货 |
| `Composite_transport_cost` | 综合运输成本 | `.35 时间+.25 距离+.25 边风险+.15(1−协同)` | 代理 |
| `Edge_capacity_proxy` | 边能力代理 | `100×两端 cap 几何平均/(1+成本)` | 代理 |
| `Repair_cost_proxy` | 修复成本 | `距离×(1+.6 边风险+.2 跨区)` | **非人民币** |
| `Failure_probability_proxy` | 失效概率代理 | `clip(边风险×(1+.2 成本), .05, .95)` | **非拟合频率** |
| `Gravity_score_exogenous` | 外生引力评分 | 端点质量几何平均`/(1+阻抗)^1.5` | 去内生度项 |

## 3 政策与参数

| 符号 | 含义 | 本项目取值 | 说明 |
|---|---|---|---|
| **ρ** | 接纳上限（相对 K） | A/B = **1.1**；C = **1** | 派入层上限 |
| **γ** | 过载退出阈值（相对 K） | 主网格 = **1**；扫描 1—1.3 | 失效层阈值 |
| `u` | 名义利用率 | `L/(γK)` = **0.800** 恒定 | 因 K=1.25L |
| **A** | 政策 A | ρ=1.1，最大化派入 X → 最小成本 | 弱基线，576 条件服务全 0 |
| **B** | 政策 B | ρ=1.1，最大化 X → 最小超额 E → 最小成本 | **强对照** |
| **C** | 政策 C | ρ=1，能力内最大化派入 → 最小成本 | 主推政策 |
| `Q` | 追加派入量 | — | 决策变量 |
| `E` | 总额定超额 | `Σ_j max(Σ_i x_ij − s_j, 0)` | 决策变量 |
| `b_j` | 本地优先承接量 | `min(D_j, K_j)` | 固定 |
| `d_i` | 来源剩余需求 | `D_i − b_i` | 固定 |
| `s_j` | 额定剩余能力 | `K_j − b_j` | 固定 |
| `u_j` | 应急承接上限 | `ρK_j − b_j ≥ s_j` | 固定 |
| **`Q_s`** | 安全最大额外承接量 | `min_U[Σ_{i∉U} d_i + Σ_{j∈N(U)} s_j]` | 最大流 |
| **`E*(Q)`** | 精确承接—超额前沿 | `max(0, Q − Q_s)` | 定理 |
| `H` | 单轮总完成量 | `Σ_j b_j + Q − E` | 定理 |
| `θ` | 风险触发阈值 | 主网格 0.1132 / 0.20 / 0.42 | 三档 |

## 4 时间域（方向 C/E）

| 符号 | 含义 | 定义 |
|---|---|---|
| `D` | 完成截止期 | 从决策时刻起算 |
| `h` | 剩余期限 | `D − t` |
| `x` | 待处理批量 | 未完成量 |
| `K` | 恢复后本地有效处理率 | 单位时间处理量 |
| `R` | 物理恢复时刻 | 未知 |
| `r` | 残余恢复时间 | `R − t`，区间 `[r_min, r_max]` |
| `τ` | 转运时滞 | 道路查询 `Duration_mins` |
| `a` | 增容启动时滞 | 合同条款 |
| `c` | 增容单价 | 无量纲 |
| `B` | 预算 | `ΔK_max = B/c` |
| **`β`** | 有效吞吐 | `mK/(m+K)`（转运率 m、处理率 K 串行） |
| **`y*(t)`** | 最低提前转出量 | `max{0, x − β(h−t−τ)}` |
| **`t*`** | 最迟等待时刻 | `min{h−τ−x/β, (C₀−x)/ρ}` |
| `y°` | 分批 minimax 平衡点 | `(r−τ+x/K)/(1/β+1/K)` |
| `C₀` | 初始接收余量 | — |
| `ρ`（时间域） | 余量流失速率 | 与静态 ρ 无关，注意区分 |
| **`q_rob`** | 最坏情景所需总转运量 | `[x − K(H−R_max)_+]_+` |
| `A(C)` | 日历总能力 | `Σ_{s=L}^{H−1} c_s` |
| **`f*`** | 临界前瞻范围 | `min{f : J_f = J_{H−1}}` |
| `J_f` | 等权总转运量 | 在预告范围 f 下 |

## 5 指标

| 指标 | 定义 | 注意 |
|---|---|---|
| `Service_Rate` | 稳定终态已完成服务 / 总需求 | **绝对水平不可解释** |
| `C−B` | C 与 B 的服务率差（pp） | 主效应量 |
| `mean_unserved_pct` | 未服务占比 = 未派入 + 已派入未完成 | — |
| `mean_not_admitted_pct` | 未派入占比 | 本项目中恒等于未服务 |
| `mean_assigned_unfinished_pct` | 已派入未完成占比 | 本项目中恒为 0 |
| `overload_only` | 仅过载触发失效的条件数 | 互斥标签 |
| `risk_only` | 仅风险触发失效 | 互斥标签 |
| `both` | 两者共同触发 | 互斥标签 |
| `mean_transfer_cost` | 代理运输成本 | **非货币** |
| `Damage_AUC` | 关键节点攻击曲线下面积 | 越大越关键 |
| `Mean J` | 恢复目标均值 | 多目标恢复 |
| 恢复 `AUC` | 恢复过程服务曲线下面积 | — |
| **承诺溢价** | 最优承诺成本 − `q_rob` | 度量日历不确定性代价 |
| `CV` | 变异系数 | 负荷集中度 |

## 6 术语（易混）

| 术语 | 本项目含义 | **不是** |
|---|---|---|
| 级联轮次 | 一次闭包内的同步传播步 | 小时/天 |
| 接纳 | 接收（可超 K） | 完成 |
| 完成 | 实际处理量（受 K 限制） | 接纳 |
| 不可逆退出 | u > γ 后永久失效 | 临时停机 |
| 自由拒收 | 允许不派入，无罚损 | 现实拒收记录 |
| 稳定终态 | 闭包不再变化时的状态 | 动态运营稳态 |
| 时间展开流 | 标准最小费用流（含时间维） | 新算法 |
| 受约束零模型 | 保度数+距离箱的随机图 | 独立城市样本 |
| 转移成本 | 尝试转移流 × 代理成本 | 人民币 |
| 双机制 | 过载触发 + 邻域风险触发 | 欠载—过载混合 |
| 表示方式 | 节点粒度 + 风险分母 + 标签 | 拓扑本身 |

## 7 单位与量纲（最容易出错）

| 量 | 单位 | 能否相加 |
|---|---|---|
| 货运量 | 万吨 | 不能与快递件数相加 |
| 货物周转量 | 亿吨公里 | 独立 |
| 快递业务量 | 亿件 | 与「寄递总量」不可替换（26.74 vs 25.05） |
| 快递收入 | 亿元 | 独立 |
| 公路里程 | 公里 | 独立 |
| 花湖货邮 | 万吨/年 | 不能当件/日 K |
| 阳逻港 | 万标箱/年 | 不能与武汉港 187.63 万标箱相加（口径疑点） |
| 丰泰 | 300 万件/日 | 设计能力，非扰动期有效能力 |
| 代理 L/K | 无量纲代理单位 | 只有相对意义 |

> **简单归一化不会自动产生业务可替代性。** 若按业务分层，各层需有自己的需求、能力及相容关系。
