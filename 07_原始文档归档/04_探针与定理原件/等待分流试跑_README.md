# 等待与分批分流：第一轮可行性试验

状态：前两轮小例验证完成；方法创新尚未通过。近邻优先2021—2026年；严格近5年为2021-10-22至2026-10-22，窗口外的直接基础工作另列。所有容量与恢复情景均为说明性设置，不来自运营标定。

## 冻结的首轮模型

一个源点、一个接收点、同质可按单位分批任务、共同截止期H。时间槽t=0,...,H−1。每槽开始只观察源点是否已恢复，再决定不可撤回的派出量。恢复时刻R取给定有限支持；本轮不估计其概率。

每槽顺序：观察→派出→本地处理及接收点处理→进入下一槽。派出后L槽到达，L=0表示当槽可处理。接收点容量c_t是已扣除其他承诺后的可用服务槽，不是可以无限保留的总额度。未用的当槽服务能力过期；任务可排队，但末期所有本地、在途及外部队列必须清空。源点恢复后每槽最多处理K，恢复前为0；无新增到达。

只允许已观察的恢复历史影响行动；未来接收点能力日历在本轮已知。后者是较强假设，用来做结构下限核查，不能推广到随机竞争。路线每槽派出上限默认不绑定，另作机制消融。

整数单位用于精确穷举；不冒充连续流体问题的新闭式解。目标先满足全部恢复情景的期限约束，再分别检查最坏转运量和等权情景总转运量。等权只是一种透明的数值比较口径，不解释成真实发生概率。

## 验证

- 独立确定性时间展开LP，对照动态规划的单一R特例。
- 独立情景树MILP，显式加恢复历史的非预见性约束，对照分批DP；整数限制与DP一致。
- 比较立即全转、固定时刻单次转运（量可优化）、最迟可行分批、同信息精确动态规划。
- 检查逐槽本地、在途、外部队列、累计服务守恒；比较无恢复观察的固定安排。
- 预定义容量日历与恢复区间网格，报告全部结果及不可行情景，不挑有效样本。

## 潜在停止条件

若最迟可行规则与精确解全面一致，且其结构只是标准流可行性/截止调度的直接结果，则计算验证通过但创新尚未通过。不能仅凭优于一次性分流就宣布有新方法。
