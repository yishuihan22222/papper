## 1. 为什么这个方向对：它修的是 V7 的结构性死因

V7 的死因不是数据少，是**结论全部落在自选参数上**：γ=1 是自选的、ρ=1.1 是自选的、K=1.25L 是构造的。所以"20 个百分点"无法外推，也无法辩护。

新题的参数结构完全不同：

| 量 | V7 | 新题 | 性质 |
|---|---|---|---|
| 转运时滞 τ | 无 | **实测 `Duration_mins`，30126 条边** | 可观测 |
| 截止期 D | 无 | 服务承诺，**由决策者设定** | 可控（政策变量） |
| 增容启动时滞 a | 无 | 合同条款，**可问供应商** | 可议 |
| 处理时间 x/K | K 是代理 | **只需比值 x/K，不需绝对 K** | 无量纲 |
| 恢复时间 r | γ 是自选常数 | **不确定，且这就是研究对象** | 被研究 |
| 退出阈值 γ | 自选、不可观测、不可控 | **不存在** | 已消除 |

关键变化有两条：

1. **最难的参数从"必须知道"变成"不需要知道"。** 新题不需要绝对容量 K，也不需要绝对需求 L，只需要处理时间 x/K 这个比值。V7 的标定死结自动消失。
2. **不确定性从"隐藏缺陷"变成"研究对象"。** V7 里 γ 不确定是致命伤；新题里 r 不确定是论文题目本身。同一个"参数不确定"，位置一换，性质就反了。

还有一条连续性：V7 的核心机制是"派入规则自己把节点推过阈值"。在时间域里它变成 **"按最短提前期分流，会把货集中到恢复最快的点，把那个点的排队推长，于是它不再是最快的"**——同一个自致失效机制，但参数量是实测的、阈值是闭式的。**这不是换方向，是把同一个机制搬到能被测量的坐标系里。**

## 2. 实测数据先否掉了一个维度：三向交互只在 D ≤ 12h 成立

我从 `04c_武汉边代理属性_候选全边.csv` 取了全部 30126 条边的 `Duration_mins`（实测道路通行时间）：

| 统计量 | 值 |
|---|---|
| 中位数 | 55.8 min |
| p90 | 98.4 min |
| p99 | 142.3 min |
| **最大值** | **193.2 min = 3.22 h** |

相对截止期的占比：

| 截止期 D | τ_max/D | τ_p50/D | 通行时间超过 0.1D 的边占比 |
|---|---|---|---|
| 12 h | 26.8% | 7.7% | **29.2%** |
| 24 h | 13.4% | 3.9% | 0.9% |
| 48 h | 6.7% | 1.9% | 0.0% |

**结论一（可写进论文的范围界定）：**

> 在武汉城域网络上，转运时滞的上界是 3.22 小时。当截止期为 12 小时，通行时间最多占截止期的 27%，三段时间尺度可比；当截止期为 24 小时以上，通行时间占不到 14%，**"转运时滞"这一维基本不构成约束**。

**结论二（支配条件，实测得出，不是构造）：**

完成时刻只依赖三者中的最大值：`起点 = max(τ, r, a)`。因此

> **恢复时间超过 3.22 小时，转运时滞就不再是瓶颈；低于 3.22 小时，才需要比较 τ 与 r。**

这条边界不是我设的，是 30126 条实测边的最大值。**它可以直接当作论文的一条结果。**

**所以论文必须把场景锁在当日达/次晨达（D ≤ 12h）。** 这不是缩小范围求稳，是数据指定的唯一有内容区间——D 越大，三个时间尺度越不成比例，题目越空。

## 3. 四个问题的闭式答案（都可证、都可执行）

记号：批量 x，截止期 D（从决策时刻起算），本点恢复时间 r（估计 r̂，实际 r̂+δ），候选点 j 的转运时滞 τ_j、处理速率 K_j，可购增容 ΔK（单价 c），启动时滞 a，预算 B（故 ΔK_max = B/c）。

### Q1 何时等待、何时分流

- 留在本点：`lead_i = r_i + x/K_i`
- 分流到 j：`lead_j = max(τ_ij, r_j) + x/K_j`
- **规则：选 lead 最小的接收点；若本点最小则等待。**

支配条件（可直接写成命题）：

> 等待优于全部分流 ⟺ `r_i + x/K_i ≤ max(τ_ij, r_j) + x/K_j` 对所有 j 成立。

**关键退化**：当 `r_j > τ_ij`（由 §2，只要恢复时间超过 3.22h 就成立）且 K 相近时，条件退化为 **`r_i ≤ r_j`**——**运输时间完全不进入判断，只比谁恢复得快。**

这就是"哪些条件下应该等待"的答案：**恢复时间大于运输时间的常态下，决策与运输无关，只与恢复时间排序有关。** 反直觉，但实测支持。

### Q2 什么时间点以后加钱也救不了

可行性：`max(τ, r, a) + x/(K + B/c) ≤ D`。

若必须在时刻 t 决定购买、增容在 t+a 到位，则

> **t\* = D − a − x/(K + B/c)**

且 **B → ∞ 时 t\* → D − a**。

> **命题：预算只能压缩处理时间 x/(K+B/c)，永远压缩不了启动时滞 a。超过 D − a 之后，任何预算的边际价值恒为零。**

这是全篇最硬的一条：闭式、可证、不依赖任何标定、任何决策者都能直接用。而且它比"预算不够"强得多——它说的是**钱有时间上的不可及区**。

补充：所需增容 `ΔK* = x/(D − max(τ,r)) − K`，当 `max(τ,r) → D` 时 **ΔK\* → ∞**。所以不是"贵"，是**在临界点附近无解**。

### Q3 预算投运输还是投接收端能力

- 投运输（降 τ）：收益 = Δτ，但**一旦 τ 降到 r 以下，边际收益立刻归零**——全有或全无。
- 投能力（增 K）：收益 = `x/K − x/(K+ΔK)`，**连续、递减、但永不为零**。

由 §2，τ ≤ 3.22h 而 r 通常为数小时至数天，**绝大多数情形 τ < r，故运输投入的边际收益为零**。

> **结论：预算应优先投接收端处理能力，而非运输。这个结论由 30126 条实测通行时间决定，不是由构造参数决定。**

这是四个问题里唯一能给出"投钱方向"的，也是最有现实分量的一条。

### Q4 按预计恢复时间制定方案，遇到延迟损失多少

损失是**阶跃**的，不是渐进的：

```
L(δ) = 0         若 max(τ, r̂+δ) ≤ D − x/(K + B/c)
     = x（整批丢失）   否则
```

临界值（当 r̂ ≥ τ 时）：**δ\* = D − x/(K + B/c) − r̂**

> **恢复时间预测误差造成的损失不是连续的，是一个悬崖：误差在 δ\* 以内损失为零，越过 δ\* 损失为整批。**

缓解规则（newsvendor 结构，可直接用）：

> 按延迟分布取 α 分位预留时间缓冲，α = V/(V + c_over)，V 为整批价值，c_over 为提前增容/提前分流的额外成本。因 V ≫ c_over，α 接近 1，**应取高分位（如 90%），不能取均值**。

这解释了为什么"按平均恢复时间做方案"系统性危险：均值对应 α=0.5，而损失函数是悬崖型，均值方案在 50% 的情形下整批丢失。

## 4. 最大的风险不是数据，是"这是已知问题"

**你自己的 91 号审计已经写明：确定性缓冲问题可以写成标准时间展开最小费用流；92 号进一步写明，当节点可用时序可预先计算时，问题又回到标准时间展开费用流。**

这意味着：**优化部分不是创新。** 审稿人会说"这是带截止期的时间展开流，CPM/PERT 以来就有"。

所以贡献只能落在三处，而且必须显式与标准时间展开流基线对比（你自己的审计文档就是这么要求的）：

1. **瓶颈归并**：证明决策只依赖 `max(τ, r, a)`，并用实测数据给出 τ 维被否掉的边界（3.22h）。这是可迁移的实证结论。
2. **预算失效时刻 t\* = D − a − x/(K+B/c)**：闭式判据，工程可直接用。
3. **阶跃损失 + 临界分位缓冲**：把"恢复时间预测误差"从连续风险转成可管理的阈值风险。

**只有这三条 → 3 区。要到 2 区，必须做第四件：分流的拥塞耦合。**

分流会改变接收点的 x/K，从而改变它的 lead，于是"选 lead 最小"不是简单 argmin，而是一个**不动点**：

> 每个批次都按最短 lead 分流 → 最快的点被填满 → 它的 x/K 上升 → 它不再最快 → 规则自我否定。

这就是 V7"自致过载"的时间域版本，而且它可以给出**个体最优与系统最优的差距（price of anarchy）**。这个量是 2 区真正认可的东西：有机制、有界、可计算、可迁移。

**判断：不做这一件，是 3 区；做成了，够 2 区边缘。做不成（比如 PoA 小于 2%，差距可忽略），退回 3 区版本，不硬凑。**
