# 核心命题怎么推出来：从一句话到可证的命题

日期：2026-10-22。目标是把"分流把恢复时间的估计系统性推向悲观，偏差随分流规模增长，按历史误差标定的安全缓冲必然失效"这句话，拆成可推导、可验证、可写进论文的形式。

---

## 0. 先拆句：这句话里其实有四个断言

| 断言 | 内容 | 证法 | 难度 |
|---|---|---|---|
| A | 偏差是单边的（只会更悲观） | 单调性，一步 | 易 |
| B | 偏差随分流规模增长 | 求导 | 易 |
| C | 按历史误差标定的缓冲必然失效 | 分布不等式 | 中 |
| D | 提前分流在多数情形下多余 | 区域占比统计 | 中（需定义"多数"） |

**A 和 B 是算术，不是发现。真正能撑论文的是它们的组合效应——排序反转。** 见 §2。

---

## 1. 记号与两个机制

对接收点 j：估计恢复时间 `r̂_j`（由无分流时期的历史得到），名义已承诺负荷 `x̂_j`，处理速率 `K_j`，分流量 `y_j`。

令**无量纲分流强度**

```
σ_j = y_j / (K_j · r̂_j)        （分流带来的处理时间 ÷ 估计恢复时间）
```

两个机制：

- **M1（处理时间项）**：实际处理时间 = `(x̂_j + y_j)/K_j`，比估计多 `y_j/K_j = σ_j r̂_j`。
- **M2（恢复时间本身）**：历史 `r̂_j` 是在**正常负荷**下观测的。分流把负荷推高，恢复（回到名义吞吐）需要清空更大积压，故实际恢复更长。取最简形式

```
r_eff = r̂_j (1 + κ σ_j),   κ ≥ 0
```

`κ` 是"恢复对负荷的弹性"。**κ=0 表示恢复与负荷无关——这就是零模型，必须跑。**

**估计提前期**：`L̂_j = r̂_j + x̂_j/K_j`
**实际提前期**：`L_j = r̂_j(1+κσ_j) + x̂_j/K_j + σ_j r̂_j`

相减：

```
L_j − L̂_j = σ_j r̂_j (1 + κ) = (1+κ) · y_j / K_j
```

---

## 2. 断言 A、B：偏差单边且线性增长

- `y_j = 0` ⇒ 偏差 = 0。**不分流就没有偏差。**
- `y_j > 0` ⇒ 偏差 > 0，且与 `y_j` 成正比。

```
偏差 = (1+κ) · y_j / K_j
```

**这是全篇最简洁的一行，也是它的弱点**：审稿人会说"多装货就多花时间，这是 Little 定律"。

**所以不能把这一行当贡献。** 贡献在下一步。

---

## 3. 真正的命题：排序会反转

设两个候选点 j、k，估计提前期 `L̂_j < L̂_k`（j 看起来更快）。分流后：

```
L_j = L̂_j + (1+κ) y_j / K_j
L_k = L̂_k + (1+κ) y_k / K_k
```

**反转条件**：

```
L̂_k − L̂_j  <  (1+κ) · ( y_j/K_j − y_k/K_k )
```

> **命题 1（排序反转）**
> 估计上的领先幅度小于分流造成的处理时间差时，被判定为"更快"的点在分流后反而更慢。
> 领先幅度越小、分流越集中、κ 越大，反转越容易发生。

**这条不是算术。** 它说的是：**用估计提前期排序的规则，会在自己的排序结果上失效。** 而且它给出了失效的**充分条件**，可以事前判断。

**直接推论（可执行规则）**：

> 分流规则应当按 **`L̂_j + (1+κ) ŷ_j / K_j`** 排序，其中 `ŷ_j` 是**预期会分流到该点的量**；不能按 `L̂_j` 排序。

这就是"稳定、可执行的分流规则"的答案：**用"分流后的提前期"排序，不用"当前估计的提前期"排序。** 前者是不动点，后者是它的第一次迭代。

**并且：第一次迭代与不动点之间的差，就是你的效应量。** 这给了一个干净的数值口径。

---

## 4. 断言 C：缓冲必然失效（闭式）

标准做法：用无分流历史误差 `δ_hist = r_actual − r̂` 拟合分布 `F`，按临界分位 `α = c_shortage/(c_shortage + c_excess)` 设缓冲 `β = F⁻¹(α)`。

分流后实际误差：

```
δ = δ_hist + (1+κ) y_j / K_j
```

**实际服务水平**：

```
SL(σ) = 1 − F( β − (1+κ) y_j/K_j )  <  1 − F(β) = α
```

> **命题 2（缓冲失效）**
> 只要分流量 `y_j > 0`，按无分流历史标定的缓冲实际服务水平严格低于名义水平 α；缺口随 `y_j` 单调增大。
> **修正量 `Δβ = (1+κ) y_j / K_j`**——缓冲必须按分流强度线性加厚。

**这一行就是可直接写进规范的设计规则**：

> 安全时间缓冲 = 历史误差分位数 + (1+κ) × 该点预期分流处理时间。

## 5. 断言 D：为什么"提前分流多数多余"与前面不矛盾

这是最容易被审稿人抓的一处，必须主动处理。

两个断言看似冲突：如果多数情形该等待，那分流很少发生，偏差也就很少发生，"必然失效"就没那么重要。

**化解方式（也是论文最漂亮的一处）**：

- 大部分参数空间落在**必然等待区**（`r_max + x/K ≤ 剩余期限`）→ 不该分流，也就没有偏差。
- 分流只发生在**赌区**（`r_min + x/K ≤ 剩余期限 < r_max + x/K`）。
- **而赌区正是偏差最致命的地方**——因为赌区的定义就是"估计刚好卡在边界上"，此时 `L̂_k − L̂_j` 本来就小，正是命题 1 里反转最易发生的区间。

> **所以：偏差不是均匀分布的噪声，它精确地集中在决策最关键的窄带里。** 稀有，但每次都致命。

这句话比"偏差很大"有力得多，而且**可检验**：在赌区内测反转频率，在赌区外测，两者应当显著不同。

**但"多数情形"必须量化**：不能说"多数"，要说"在 D ∈ {6,12,24}h、x/K ∈ [0.1D, 0.5D]、r ∈ [1h, 10d] 的网格上，X% 的格点落在必然等待区"。**没有这个百分比，这句话就是修辞，不是结果。**

## 6. 这句话在什么条件下是假的（必须写进论文）

| 条件 | 效果 | 为什么重要 |
|---|---|---|
| 集中调度（一个决策者统筹全部分流） | 偏差被内部化，命题不成立 | 说明本文结论适用于**规则型/分散分流** |
| 容量可弹性增加（随时加人加设备） | M1 消失，`y/K` 不成立 | 本文假设**容量短期刚性** |
| `κ = 0` 且负荷不影响恢复 | 只剩 M1，退化为 Little 定律 | **零模型，必须作为对照跑** |
| 用含分流的历史数据重新标定 | 缓冲不再失准 | 本文主张限定为"按无分流历史标定" |
| `y_j / K_j → 0`（批量相对容量很小） | 偏差 → 0 | 给出适用下限 |

**五条里前两条是设定，第三、五条是可检验的，第四条是主张的精确边界。** 全部写清楚，这句话就站得住。

## 7. 用现有代码怎么验证（成本很低）

| 步骤 | 做什么 | 复用 |
|---|---|---|
| 1 | 取 122 点网络 + 真实 `Duration_mins`（1624 边，max 63min） | `model_inputs/edges.csv` |
| 2 | 设 `κ ∈ {0, 0.25, 0.5, 1.0}`，`κ=0` 为**零模型** | 新建，几十行 |
| 3 | 跑两种排序：`L̂` 排序 vs `L̂ + (1+κ)ŷ/K` 排序（不动点迭代） | 91 号 LP 骨架 |
| 4 | 统计：反转发生率、反转幅度、赌区内外的差异 | 现有核对与交付流程 |
| 5 | 对每个 σ，计算实际服务水平 `SL(σ)` 与名义 α 的缺口 | 直接算 F |
| 6 | 断言：`κ=0` 时反转率应为 0 或极小；`κ↑` 时单调上升 | 五类守恒断言 |

**关键检验**：`κ=0` 时若反转率仍显著大于零，说明反转来自**共享容量**而非恢复-负荷耦合——这仍然是结果，但命题 1 的归因要改。**先做这一步，再决定命题怎么写。**

## 8. 论文里的呈现形式（三段）

**命题 1（排序反转）** + 反转的充分条件。
**命题 2（缓冲失效）** + 修正量 `Δβ = (1+κ)y/K`。
**推论（规则）**：按分流后的提前期排序；第一次迭代与不动点之差即效应量。

**外加一个必须有的对照表**：`κ=0` 时两条命题退化为什么。**没有这张表，命题会被认为在给 Little 定律换名字。**

---

## 9. 一句话

**这句话不是"想"出来的，是三步推出来的：把偏差写成 `(1+κ)y/K`（一步），证明它导致排序反转（这是命题），再证明历史缓冲因此失准（这是推论）。**

**其中唯一可能被质疑的是 `κ>0`——所以 `κ=0` 的零模型必须跑，而且必须先跑。**
