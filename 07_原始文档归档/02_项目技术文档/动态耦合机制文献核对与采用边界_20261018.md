# 动态耦合机制文献核对与采用边界

日期：2026-10-18。独立方法审计，不是论文正文。本记录结合92b小网络的条件性结果与定向文献核对，决定哪些机制可以继续论证。不是穷尽查新，也不将文献中的系统直接等同于武汉混合设施网络。

## 1. 当前采用决定

不把“库存连续超过普通缓冲L期就永久退出”直接并入主线。92b说明这一假说能够产生跨期收益与失效风险的取舍，但没有建立该退出规则的现实依据。

下一分支优先研究有限缓冲引起的可恢复阻塞与吞吐损失，保留原模型作为独立、已冻结的条件性基线。先明确货流通道、处理能力、等待位置和阻塞解除条件；缺少这些信息时，仅开展合成结构研究，不对246个混合POI统一赋予同一仓储机械故障规则。

## 3. 92b真正增加了什么证据

所有数量指预先固定的合成配置，不是独立实测样本或事件发生概率。每个持续期L共648个配置，包含两种时域、等待费、传播结构及外部冲击；合计2592个配置、12960条政策评价。

|候选规则|相对普通安全缓冲，精确最优有改善|真正改变最优值的配置|解释|
|---|---:|---:|---|
|超过普通缓冲1期即退出|0/648|115/648|重新回到应急库存没有未来完成机会、安全缓冲结构性充分的情形|
|超过普通缓冲连续2期才退出|115/648|15/648|存在短时有益、持续有害的条件性取舍，但并非整个网格都有决策反馈价值|
|连续4期才退出|115/648|0/648|在本到达与有限时域设计中，退出条件没有改变最优值；不能推广到更长时域|
|关闭积压引起的退出|115/648|0/648|回到已知可用时序的标准时间展开费用流|

“真正改变最优值”比较的是正确候选规则下的精确最优与移除内生退出后的乐观最优，而非一个忽略规则的执行策略与另一个策略的排名。

L=2时，忽略规则的规划器在18个配置执行次优，其中15个同时有真实最优值差；剩余3个没有最优值差，不能排除等价最优计划选择或滚动执行偏差。不能将18个全部宣传成新机制带来的独立优化能力。

这15个真实最优值差均出现在追加两期清空的版本；原三期版本没有。必须同时呈现两种时域。该结果说明未来可用处理时段会影响反馈的价值，不能把有利时域单独当作普遍证据。

完整小例[0,6,3,0,0]在L=2、等待费0.1、无传播时，无退出乐观最优1.9，真实候选规则最优2.6。它排除了“只是挑了一个不好的同成本方案”对最优值差的解释，但没有证明候选退出规则真实或方法新颖。

## 4. 建议保留的下一分支设计条件

1. 分开永久物理损伤F与可恢复运营阻塞C(t)。外部灾害可以造成F；有限空间可造成C(t)，两者不能共用一个不可逆标签。
2. 明确阻塞对象是入口、共享通道、处理站还是整个设施。下游队列满通常不意味着它连库存都无法继续处理；若关闭它全部处理能力，可能人为制造永远无法清空的死锁。
3. 用流量/空间守恒表示下游无余量导致的上游等待与吞吐受限。库存继续留在队列或上游，不能因堵塞凭空销毁。接受后损失需要另外的货损依据。
4. 设置恢复条件，例如下游释放空间后解除阻塞。恢复阈值、时段和任何滞后仍应标明证据来源；不凭空拟合到漂亮曲线。
5. 先与时间展开费用流、有限缓冲阻塞模型及精确小例比较。可恢复阻塞也不自动意味着标准流失效，更不自动需要元启发式。
6. 先检查可行性、零需求清空、无外部损伤稳定、节点编号对称性，以及优化目标是否能通过囤货、毁货、时域截断获得虚假优势。
7. 若有资格进入原网络，仍需决定哪些节点是物理设施、边是否代表真实货流通道；当前代理边和混合POI不提供仓内机械依赖。全网扩展之前解决概念口径，不以更多随机种子替代。

## 5. 不应做的推断

- 不把“存在可构造的非平凡小例”写成“已获得新算法或复杂性定理”。
- 不把离线全知最优优于受限策略写成现实控制器性能。
- 不把两节点有向传播的结果写成已复现V5加权风险公式或城市风险传导。
- 不把本次未找到匹配永久退出证据，写成全世界不存在这类证据。
- 不把标准模型识别或诚实审计直接换算成SCI分区与录用把握。

当前最稳妥的定位仍是：冻结已有静态结果，保留动态状态与守恒账本，用合成小例界定机制边界；新的运营机制只有在语义与证据足够时才升级为主线模型。
