# V5恢复停步诊断与预算—时域实验

本轮按“先查停步，再分离预算与时域，最后有条件检查两步/成组修复”的顺序完成。没有覆盖旧V5、改变正式数据、风险阈值或过载规则。16个原模型/损伤条件全部保留；预算4/8/12×时域6/12完整交叉，96个条件、288个方案、1152条需求评价。预算是归一代理修复资源，时域是行动/观察步数，不是已验证的货币或天数。

主要结果：留出需求中，贪心相对负载优先的平均服务AUC优势由预算4/时域6的0.20284个百分点变为预算12/时域12的0.26867个百分点；中位优势分别为0.00000和0.00000个百分点。扩大设置下有1个配对条件略差，并非普遍胜出；这两个端点同时改变了预算与时域，只作概览，单因素对照另列。三个非吸收停步条件的完整可负担两步扩展中，1个条件找到规划目标正增益。单纯扩大资源没有消除所有零行动停步，应结合下面的状态/触发原因决定优化方向。

## 4. 如何据此决定下一步

先看68d中同一时域增加资源能否提高服务，再看68a/c中这种提高是否形成相对负载优先的优势。若有预算但全部单点恢复仍返回原失效状态，继续加预算或给贪心更多搜索次数并不能解决同一可负担动作集的问题，应先审查持续风险与修复投运规则是否符合研究对象。任何修复保护期、灾害衰减、联合投运或排队机制都需要独立的新模型假设，不能为了获得算法差异直接加入。

对确有非零状态变化、又存在两步正收益的停步，可以研究有限前瞻；没有找到两步收益时，不应直接宣称换复杂算法就会有效。保留负载优先和单步贪心。算法是否有用要结合稳定服务、累计资源和计算开销，而不是只看最终修复个数。搜索时间使用共享热缓存，不能用本轮计时作严格算法加速比或等计算预算证明。

基于本轮结果，下一版建议并行保留两个清楚的研究方向：在可恢复状态上检验有限前瞻的稀疏收益；在单点吸收状态上先研究符合业务含义的承接准入与修复投运规则。严格准入零行动条件中主要为传播触发，应急准入条件中大量同时触发过载与传播，不能只删除其中一项来制造恢复。没有证据支持把预算12/时域12替换为唯一主设置，也没有证据支持立即引入更复杂元启发式。
