# 代理变量与估算指标：依据、构造与适用边界

**版本**：2026-10-12（与修正后 15% 稀疏网络及全链路结果同代）
**用途**：回答审稿人「节点容量、风险暴露、修复成本这些变量是怎么来的」的追问；同时为论文附录提供可直接引用的方法段落。

---

## 0. 一句话总览

本文网络中**只有边的时间/距离来自高德 API 实测**，其余节点与边的属性**全部是结构化代理变量（proxy）**，构造规则完全透明、可复现。代理变量的设计原则是：**只用外生可观测信息（设施类型、区县 GDP、公开枢纽数据），不使用网络拓扑衍生量作为网络自身的输入**，以避免循环论证。

## 1. 数据来源分层

| 层级 | 变量 | 来源 | 性质 |
|---|---|---|---|
| L1 实测 | 边 `Distance_km`、`Duration_mins`、`Generalized_impedance` | 高德地图路径规划 API（逐对调用，30,126 条） | **真实测量** |
| L2 公开统计 | 城市 GDP、货运量、快递业务量/收入、公路里程 | 各市 2024 年国民经济和社会发展统计公报（见 `公开补充数据_城市物流指标.csv`，含来源 URL 与发布日期） | **真实统计** |
| L3 公开统计 | 区县 GDP | `武汉各区GDP.csv`（武汉市及都市圈各区县统计口径） | **真实统计** |
| L4 公开统计 | 花湖机场货邮吞吐量、阳逻港集装箱吞吐量、易积水点等 | `公开补充数据_关键枢纽与风险指标.csv`（官方稿件，含 URL） | **真实统计** |

## 2. 节点代理变量

### 2.1 `type_weight`（设施类型权重）

按设施功能类型赋权，反映其理论物流承载等级：

| family | 判定规则（`类型` 字段正则） | 权重 |
|---|---|---|
| airport | 机场 / 空港 / 航港 / 花湖 | 1.00 |
| port | 港 / 码头 / 阳逻 / 新港 / 集装箱 | 0.95 |
| rail | 铁路 / 火车站 / 班列 / 汉欧 / 武铁 | 0.90 |
| bonded | 综保区 / 保税 | 0.85 |
| distribution | 分拨 / 分拣 / 转运 | 0.80 |
| coldchain | 冷链 / 农产品 | 0.75 |
| park | 物流园 / 物流基地 / 货运中心 / 货运站 / 仓储 / 仓库 | 0.70 |
| other | 其余 | 0.55 |

**依据**：层级来源于物流设施功能分级的一般认识（枢纽型 > 口岸型 > 分拨型 > 仓储型），权重间距（0.05 等距）为便于解释的人工设定。**敏感性边界**：现有 §5 检查改变的是稀疏保留比例和引力指数，并未单独扰动 `type_weight`；因此不能声称该权重已经过独立稳健性验证。

### 2.2 `hub_weight`（枢纽加成）

| 条件 | 权重 |
|---|---|
| family ∈ {airport, port, rail} | 1.00 |
| family = bonded | 0.88 |
| 名称含 京东/中通/韵达/安能/邮政/百世/跨越 | 0.85 |
| family ∈ {distribution, coldchain} | 0.78 |
| family = park | 0.68 |
| 其余 | 0.50 |

**依据**：区分「国家级/区域级枢纽」与「普通节点」。头部物流企业命名的设施被视为具备真实运营能力。

### 2.3 `district_gdp` / `district_gdp_norm`

- 原始值：按 `区县` 匹配 `武汉各区GDP.csv` 的 `地区生产总值`（亿元）。
- 归一化：min-max 到 [0,1]。
- **注意**：`alias()` 函数对三个特殊行政区做了名称映射（东西湖→武汉临空港经济技术开发区(东西湖区)、汉南→武汉经济技术开发区(汉南区)、东湖高新→东湖高新技术开发区），以保证与 GDP 表的统计口径一致。

### 2.4 `risk_exposure`（风险暴露）

按区县赋值的固定字典：

| 区县 | 风险值 | | 区县 | 风险值 |
|---|---|---|---|---|
| 新洲区 | 0.68 | | 洪山区 | 0.47 |
| 黄陂区 | 0.62 | | 汉阳区 | 0.46 |
| 东西湖区 | 0.58 | | 江岸区 | 0.44 |
| 汉南区 | 0.57 | | 硚口区 | 0.43 |
| 江夏区 | 0.55 | | 武昌区 | 0.42 |
| 蔡甸区 | 0.52 | | 江汉区 | 0.41 |
| 青山区(武汉化工区) | 0.51 | | 其他 | 0.45 |

**依据**：外环新城与产业区（新洲、黄陂、东西湖等）货流集中、承压大，风险暴露高；中心城区（江汉、武昌等）以生活物流为主，风险暴露低。这是**本文设定的专家型先验**，非实测风险数据。

> **⚠️ 论文必须交代**：该变量是主观先验，建议在论文中明确表述为「基于区域功能定位的风险暴露先验赋值」。它不仅进入 `Failure_probability_proxy`，也间接进入 06 的 SVD-Bridge 脆弱性评分及后续级联/恢复模块，因此必须作为模型局限而不是实测风险陈述。

### 2.5 `capacity_index`（综合容量指数）

```
capacity_index = 0.35*type_weight + 0.20*district_gdp_norm
               + 0.25*weighted_degree_norm + 0.20*hub_weight
```

- `weighted_degree_norm` = `weighted_degree_proxy` 的 min-max 归一化，其中
  `weighted_degree_proxy = Σ_e 1/(0.6*Duration_mins + 0.4*Distance_km)`（按 node_id 聚合）。

> **⚠️ 循环性说明**：`capacity_index` 含 `weighted_degree_norm`，而度来自边——若再用 `capacity_index` 去剪边，会构成循环依赖。**这正是稀疏化采用「外生质量」（仅含 type_weight / district_gdp_norm / hub_weight，不含度）的原因**。`capacity_index` 只用于下游韧性/恢复分析的节点承载能力刻画，不用于网络剪枝。

### 2.6 `proxy_daily_load` / `overload_threshold`

```
proxy_daily_load     = 50 + 950 * capacity_index      (吨/日，代理)
overload_threshold   = 1.25 * proxy_daily_load
```

**依据**：以 `capacity_index` 线性映射到日处理量代理区间 [50, 1000] 吨；过载阈值取 1.25 倍。这两个量**是相对量纲的代理**，用于韧性模型内部比较，**不代表真实吞吐量**。

> **⚠️ 论文必须交代**：这是量纲代理（dimensionless proxy），论文中不可表述为「日处理 X 吨」。建议表述为「归一化负载压力指数」。

## 3. 边代理变量

### 3.1 `Generalized_impedance`（广义时空阻抗）— 实测派生

```
边层: Generalized_impedance = 0.6 * Duration_mins + 0.4 * Distance_km
城市引力层: Z = Duration_norm + 0.5 * Distance_norm
```

由高德 API 的行驶时间与路网距离派生。边层保留有量纲的 0.6/0.4 组合；城市引力层先在 8 城截面内分别做 min-max 归一化，再按论文公式取 `Z=t'+0.5d'`。为避免最近城市在两项同时取最小值时出现零阻抗奇点，引力层仅对 Z 设置 `1/N` 下界（N=8）。

### 3.2 `Functional_synergy`（功能协同度）

两节点 family 组合的固定映射（对称）：

| 组合 | 值 | | 组合 | 值 |
|---|---|---|---|---|
| airpot-bonded | 0.86 | | coldchain-distribution | 0.84 |
| airport-distribution | 0.88 | | distribution-park | 0.75 |
| bonded-distribution | 0.82 | | distribution-port | 0.78 |
| bonded-park | 0.76 | | port-rail | 0.90 |
| park-rail | 0.82 | | 同类型 | 0.70 |
| 其他组合 | 0.35 | | | |

**依据**：反映不同功能设施之间「协同作业可能性」。如「空港—保税」用于国际中转，「水港—铁路」用于铁水联运，均为已知的高协同组合。

### 3.3 `Risk_exposure_proxy`（边风险）

```
Risk_exposure_proxy = 0.5 * (risk_s + risk_t)/2 + 0.3 * Cross_district + 0.2 * Duration_norm
```

节点风险均值占 5 成，跨区占 3 成，耗时占 2 成。

### 3.4 `Composite_transport_cost`（综合运输成本代理）

```
Composite_transport_cost = 0.35*Duration_norm + 0.25*Distance_norm
                         + 0.25*Risk_exposure_proxy
                         + 0.15*(1 - Functional_synergy)
                         (下限截断至 0.01)
```

**含义**：时间与距离推高成本，风险推高成本，功能协同降低成本。新写法与旧式 `-0.15*synergy` 只相差常数 0.15，因而不改变边的成本排序；但可避免旧式中大量边被截到 0.001、从而在逆成本效率中占据过高权重。当前正式边的成本范围为 0.0943–0.4072，无下限堆积。

> **⚠️ 循环性说明**：该变量含 `Risk_exposure_proxy`，而后者含节点 `risk_exposure`（外生）——**不含网络度**，故理论上可用于剪枝；但初版稀疏化误用该变量并叠加了度衍生项，已纠正为外生引力法（详见《稀疏化实施与复核报告》）。

### 3.5 `Edge_capacity_proxy`（边容量代理）

```
Edge_capacity_proxy = 100 * sqrt(capacity_i * capacity_j) / (1 + Composite_transport_cost)
```

几何平均体现「两端都强边才强」，成本作分母体现「越难运越少」。

### 3.6 `Repair_cost_proxy`（修复成本代理）

```
Repair_cost_proxy = Distance_km * (1 + 0.6*Risk_exposure_proxy + 0.2*Cross_district)
```

**依据**：修复成本与物理距离正相关，风险与跨区提高施工难度系数。

### 3.7 `Failure_probability_proxy`（失效概率代理）

```
Failure_probability_proxy = min(0.95, max(0.05, Risk_exposure_proxy * (1 + 0.2*Composite_transport_cost)))
```

截断在 [0.05, 0.95]，避免概率取 0 或 1 导致仿真退化为确定性。

## 4. 城市指标估算（04a）

`04a_城市综合指标_含估算.csv` 中 5 项物流指标有缺失，采用两种规则补全，并**逐行标注估算方式**：

| 指标 | 公开数据城市数 | 估算城市数 | 估算方法 |
|---|---|---|---|
| 货运量_万吨 | 1 | 7 | GDP比例中位数估算 |
| 货物周转量_亿吨公里 | 5 | 3 | GDP对数回归估算 |
| 快递业务量_亿件 | 4 | 4 | GDP对数回归估算 |
| 快递业务收入_亿元 | 4 | 4 | GDP对数回归估算 |
| 公路里程_公里 | 4 | 4 | GDP对数回归估算 |

**估算规则**：
- **GDP 对数回归**：当有效样本 ≥3 且均为正，对 `(ln GDP, ln 指标)` 做最小二乘拟合，回代预测。
- **GDP 比例中位数**：样本不足时退化为 `指标 = median(指标/GDP) × GDP`。

> **⚠️ 论文必须交代**：`运输量` 一项仅武汉有公开数据，另 7 城全为估算，是精度最弱的指标。它进入 `需求强度指数` 时权重 0.3。建议在附录列明每个城市的估算方式（数据文件已含 `*_估算方式` 列，可直接转成附录表）。

## 5. 代理变量对结论的影响（已做的验证）

| 验证项 | 结果 | 出处 |
|---|---|---|
| 稀疏化是否用外生质量（不含度） | 是，`exogenous_mass = (0.35*type_weight + 0.20*district_gdp_norm + 0.20*hub_weight)/0.75` | `24_sparsify_network.py` |
| 保留比例 14/15/20% 下 top200 结构排名代理 | Jaccard ≥ 0.9324，高度一致 | `25_sensitivity_rank_overlap.csv` |
| β=1.0–2.0 边集相似度 | Jaccard ≥ 0.9638 | `25_sensitivity_beta.csv` |
| 三档下层 LCC / 需求可达率 | 全部 = 1.0000 | `25_sensitivity_downstream.csv` |

**结论边界**：现有敏感性结果支持“稀疏网络的连通性与结构排名代理对保留比例、β 的设定较稳定”。它不等同于对 05–09 全部动态级联、恢复与优化结果做了完整重跑，因此不应扩展表述为“全部韧性结论均不变”。

## 6. 论文写作建议（措辞模板）

### 建议写入方法部分

> 由于设施级实时运营数据不可公开获取，本文采用**结构化代理变量**刻画节点与边的物流属性。边的时间与距离来自高德地图路径规划 API 的逐对实测；城市与区县级经济物流指标来自各市 2024 年国民经济和社会发展统计公报及武汉市各区统计资料；设施类型权重、枢纽加成与功能协同度依据物流设施功能分级的一般认识设定；风险暴露为基于区域功能定位的先验赋值。所有代理变量的构造规则完全透明，并在正文中给出公式与参数。

### 建议写入局限性部分

> 本文的节点容量、风险暴露与修复成本为代理变量，其绝对量纲不代表真实运营数值，仅用于模型内部的相对比较与排序。其中风险暴露为专家先验赋值，运输量指标对 8 个城市中的 7 个采用 GDP 对数回归或比例中位数估算。本文另对稀疏保留比例 14%–20% 与引力指数 β=1.0–2.0 开展结构代理敏感性检查，其结果不代替动态级联与恢复优化的全参数重跑。未来工作可在获取设施级实测数据后替换代理变量。
