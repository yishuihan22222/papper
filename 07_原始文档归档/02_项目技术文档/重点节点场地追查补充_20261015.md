# 重点节点场地追查补充

完成日期：2026-10-15。目的为回答“这些设施身份和场地资料能否继续查到”。本轮发现可推进主体和项目对应核验，但仍不能声称已取得每个模型节点的独立2024年物理处理能力。正式代码、数据及前一轮证据表未修改。

## 1. 园区投资公司：有真实仓储项目依据，不能仅按公司名称认定为办公点

武汉市自然资源和规划局2019-12-24的建设工程规划许可，将行政相对人明确列为“武汉临空港综合保税园区投资发展有限公司”，项目名称为“武汉新港空港综合保税区东西湖园区跨境电商保税仓库”，文号为武规（东）建[2019]146号。原网页以GB2312声明编码，已按GB18030解码核对并保留原始字节。

来源：[建设工程规划许可](https://spxx.zrzyhgh.wuhan.gov.cn/showSgsJyh.asp?cid=2255&instanceID=SX20191224010750&type=1)。网页检索器访问不稳定，本轮通过直接下载取得原件；不得把“许可项目存在”当作“2019即建成运营”。

东西湖区政府2024-11-22《结硬账！武汉陆港枢纽建设进度条刷新》明确该公司承担建设、运营任务，跨境电商保税仓2、3号仓约4万平方米已验收交付，4号仓约2万平方米仍在施工。这提供了**同年项目状态证据**，比只引用2025回溯或2026报道更直接。

来源：[2024年建设运营报道](https://www.dxh.gov.cn/XWZX/LKGYW/202411/t20241125_2489411.shtml)。

可确认：公司与实体仓储项目有关联，并非仅有办公名称；2024年末部分库区已交付。

仍不能确认：模型中该公司POI的点位和空间范围是否等于2、3号仓、是否代表整个园区、与“保税物流园”“武汉空港综合保税区”是否重复。因此不立即删除该公司节点，也不将4万平方米直接变成其独立吨/日能力。

## 2. 申报大厅：已查到同年通关办公设施，但原POI微观对应仍待核

同一2024年官方报道明确汉口海关办公场地及综保园区通关服务中心已完工、海关当时即将入驻。这能证明存在单独的通关服务设施，同时提示启用时点不能假设为2024全年。

2026-09-20官方报道进一步明确综保大厦1—5层为海关办公业务场所，一层设置申报大厅，配套仓库另外列示。来源：[综保大厦功能报道](https://www.dxh.gov.cn/XWZX/LKGYW/202609/t20260920_2851077.shtml)。

可确认：办公/申报服务与仓库是应区分的功能范围。

仍不能确认：现有“武汉新港空港综合保税区申报大厅”POI是否对应同一楼宇、2024哪个时段、实际坐标是否为大厅入口。不能从2026楼层布局直接回推2024，更不能把所在园区全部货物能力归给大厅。

|经营单位|武汉金宇综合保税发展有限公司|
|邮政地址|湖北省武汉东湖新技术开发区光谷三路777号|
|系统场地编码|CNNHN47S006_11|

|系统显示的主管单位|武汉东湖综合保税区|

原始公开JSON、请求参数、时间和SHA-256均已保存。记录创建时间显示2025-07-29，更新时间显示2026-10-15。**这属于当前登记证据，不作为2024名录快照或处理能力值。** 历史基础编码CNNHN47S006的精确检索返回空；按名称检索可命中带后缀的新编码，无名称限制检索返回135条，不能把原来的空结果解释为设施不存在。未采集任何报关单或私人业务记录。

另有2024-11-04巨潮资讯公开披露的《北京市君致律师事务所关于河南新宁现代物流股份有限公司向特定对象发行A股股票的补充法律意见书（十）》，PDF第28页/文内4-1-27，列示光谷三路777号A塔楼7层701、702室，租赁面积521.93平方米，2023-12-01至2025-11-30，合同用途为行政办公。PDF第32页另列同一777号下B1 1#库的仓储租赁，表明大门牌下存在不同楼栋和用途。

来源：[2024年公开法律意见书](https://static.cninfo.com.cn/finalpage/2024-11-04/1221625838.PDF)。已视觉核对PDF第28页表格。

可确认：查验场是真实监管场地，经营单位和园区级邮政地址可由官方系统直接核实；A塔楼存在办公用途，777号不能视为单一作业单元。

仍不能确认：原POI标注的“A塔楼F1”是否是查验场服务入口、行政点或误标；七层办公用途不能证明一层用途，也不能给出实际查验平台、冷库边界和精确经纬度。保留真实查验场身份，不把整个场地判为办公点、不擅自搬动坐标。

## 4. 对模型数据的直接含义

- 投资公司可作为园区运营主体的候选代表点，但需先定义代表的设施范围，再判断与其他园区节点是否重复。
- 申报大厅可有通关服务功能，但不能未经定义赋予与仓库同口径的吨/日能力。
- 东湖查验场已有官方身份和经营主体，应保留身份；实际作业位置仍待核。
- 本轮新增证据未提供能直接回填的2024独立日处理能力，也没有改变花湖节点“暂按待核验保留”的用户决定。
- 已比对227个正式Code/data文件，字节一致；未删除节点、未替换容量、未重跑正式实验。
